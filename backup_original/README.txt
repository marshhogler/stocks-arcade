STOCKS ARCADE — BROWSER CLIENT

This is the browser-playable client for the existing Stocks Arcade multiplayer server.
Server URL is built in: https://stocks-arcade-multiplayer.onrender.com
WebSocket endpoint: wss://stocks-arcade-multiplayer.onrender.com/ws

To publish:
1. Upload index.html to a static website host (for example, GitHub Pages).
2. Ensure index.html is served over HTTPS.
3. Open the published URL on a computer or phone browser.
4. Choose Online Multiplayer, enter a player name, then create or join a room.

Players in this browser client and compatible Android app can use the same room code.
The server keeps rooms in memory, so a server restart or sleep/restart may end active rooms.
